# Эмулятор  для языка оболочки ОС, похожей на работу в командной строке UNIX
подобной ОС.

Конфигурационное управление. Задание для текущего контроля 1.

## Вариант №28

## Описание
Эмулятор командной оболочки с GUI (Tkinter), виртуальной файловой системой (CSV) и поддержкой базовых команд: ls, cd, wc, du, mkdir, touch.

## Функции и настройки
- `--vfs <путь>` — путь к CSV-файлу VFS
- `--script <путь>` — путь к стартовому скрипту
- Служебная команда `conf-dump` — вывод параметров
- Команды: `ls`, `cd`, `wc`, `du`, `mkdir`, `touch`, `exit`

## Сборка и запуск
```bash
pip install -r requirements.txt
python src/main.py
